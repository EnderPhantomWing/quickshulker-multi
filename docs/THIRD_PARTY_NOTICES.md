# Third Party Notices

This project, **QuickShulker-Multi**, includes or is derived from code from the following third-party open source projects.

## Upstream Projects

This project is a multi-version refactor that builds upon the work of several upstream projects:

- **[kyrptonaught/QuickShulker](https://github.com/kyrptonaught/quickshulker)**  
  The original QuickShulker mod that allows players to open shulker boxes and other containers without placing them down.  
  *License URL: https://github.com/kyrptonaught/quickshulker/blob/1.19/LICENSE*

- **[Grayer0113/quickshulker](https://github.com/Grayer0113/quickshulker/tree/1.20)**  
  Port that added support for Minecraft 1.20.4.  
  *License URL: https://github.com/Grayer0113/quickshulker/blob/1.20/LICENSE*

- **[Haocen2004/quickshulker](https://github.com/Haocen2004/quickshulker)**  
  Port that added support for Minecraft 1.20.6 and 1.21(.1).  
  *License URL: https://github.com/Haocen2004/quickshulker/blob/1.21/LICENSE*

- **[MoRanpcy/quickshulker](https://github.com/MoRanpcy/quickshulker)**  
  Upstream project that added support for Minecraft 1.21+ and fixed various bugs.  
  *License URL: https://github.com/MoRanpcy/quickshulker/blob/1.21.1/LICENSE*

## Build Tools and Frameworks

This project uses the following tools and frameworks during development and build processes:

- **Gradle** – Build automation tool used for multi-version builds.
- **Fabric Loom and Loom-Remap** – The project is built as a Fabric mod and relies on the Fabric ecosystem.
